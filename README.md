# BTI Akademia

Strona do nauki przed Białostockim Testem Informatyków: lekcje z rysunkami, pytania wielokrotnego wyboru w stylu BTI (punktacja: jedna błędna opcja zeruje pytanie), mini-sprawdziany i egzamin próbny.

Czysty HTML/CSS/JS, bez zależności i bez budowania. Postępy zapisują się w localStorage przeglądarki.

Uwaga: pytania oznaczone „Oficjalny test próbny” pochodzą z testu próbnego BTI 2026, reszta jest autorska. Poprawność odpowiedzi nie pochodzi od organizatora.
